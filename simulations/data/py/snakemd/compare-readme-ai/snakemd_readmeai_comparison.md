# SnakeMD — Paper Tool vs readme-ai Comparison

## Methodology
Comparison of the best and worst README generated by the paper tool (README-Gen) against the README generated by readme-ai, using the evaluation framework from Section 4.4.2 of *README-Gen: Evaluating A Large Language Model for API Documentation Synthesis*.

## Paper Tool Results Summary

### Best Generated README: data1.md (CR = 43.33)
- Achieves the highest correctness among the three generated READMEs. While the overall score is moderate, it provides the most accurate coverage of SnakeMD's markdown generation capabilities, though some sections (likely Installation, API Reference, or License) have gaps.

### Worst Generated README: data3.md (CR = 33.33)
- Lowest correctness due to more significant gaps in multiple sections. SnakeMD is a smaller, less well-known library, which likely contributes to the paper tool's difficulty in generating comprehensive documentation.

## readme-ai Evaluation

### Strengths
- Correctly identifies the project title as "snakemd"
- Provides accurate project structure (directory tree listing)
- Identifies Python as the primary language
- Includes correct repository URL
- Suggests `poetry install` which is closer to correct for SnakeMD (it uses Poetry for development)

### Weaknesses
- Empty Overview section (no description of SnakeMD as a markdown generation library)
- Features section contains only "REPLACE-ME" placeholder text
- Installation instructions are for development only (`poetry install`), not end-user (`pip install snakemd`)
- Usage section contains only placeholder commands
- No API Reference documentation
- Does not identify the MIT license
- No domain concepts (markdown generation, document creation, programmatic writing)
- No execution facts or usage patterns

### Section-by-Section Analysis
- **Title**: Correct — "snakemd" matches the repository name (Score: 100)
- **Overview**: Empty — no description of SnakeMD as a Pythonic markdown generation library (Score: 0)
- **Installation**: Provides `poetry install` which is partially correct for development setup. SnakeMD does use Poetry, giving slightly more relevance than other tools, but still doesn't provide `pip install snakemd` for end users (Score: 40)
- **Usage**: Placeholder commands only, no markdown document creation examples (Score: 0)
- **API Reference**: Absent — no documentation of Document, Heading, Paragraph, Table, etc. (Score: 0)
- **License**: Does not identify MIT license; provides only a generic link (Score: 0)

## Conclusion
For SnakeMD, the gap between the paper tool and readme-ai is narrower in terms of correctness (CR difference of 10-20 points) compared to more popular libraries. Both tools struggle with this smaller library's documentation. However, the paper tool still significantly outperforms readme-ai in ATRAK (100 vs 0) and Completeness (7/7 vs 2/7), demonstrating that README-Gen captures domain concepts and provides meaningful content even when its correctness is moderate. Notably, readme-ai's installation section scores higher because `poetry install` is actually relevant for SnakeMD's development workflow.
