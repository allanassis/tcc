# Evaluation Data Layout

This folder contains the README files generated by the studied tools and their
evaluation data, organized as `{language}/{package}/`.

## Per-package layout

```
{language}/{package}/
├── data1.md                      # README-Gen run 1
├── data2.md                      # README-Gen run 2
├── data3.md                      # README-Gen run 3
├── evaluation/                   # STANDARDIZED evaluation of README-Gen outputs
│                                 # (produced by simulations/standard-readme-evaluation-prompt.md)
├── evaluation-legacy/            # ARCHIVED: original evaluation of README-Gen outputs,
│                                 # produced before the standardized prompt existed
└── compare-readme-ai/
    ├── {pkg}_readme_readmeai.md  # README generated by README-AI (input artifact)
    ├── evaluation/               # STANDARDIZED evaluation of the README-AI output
    │                             # (same prompt and rubric as README-Gen's evaluation/)
    └── legacy/                   # ARCHIVED: original ad-hoc comparison artifacts
                                  # ({pkg}_comparison_reasoning.md, {pkg}_comparison_readmeai.csv)
```

## Legacy vs standardized

- **Legacy** (`evaluation-legacy/`, `compare-readme-ai/legacy/`): the original
  results. The README-Gen evaluations followed the TCC methodology but were
  driven by an ad-hoc prompt; the README-AI comparison was entangled with the
  evaluation (README-AI output was judged inside the comparison flow instead of
  being independently evaluated with the same protocol). Kept for reference and
  drift analysis; do not use as input for new comparisons.
- **Standardized** (`evaluation/`, `compare-readme-ai/evaluation/`): produced by
  the generic, tool-agnostic evaluation prompt
  (`simulations/standard-readme-evaluation-prompt.md`) applied symmetrically to
  both tools, parameterized by `simulations/tcc-run-manifest.md`. Comparisons
  are generated exclusively from this data via
  `simulations/readme-evaluation-comparison-prompt.md`.

## Known naming quirks (kept intentionally)

- `js/jquey/` — folder name typo for jQuery; file prefixes inside follow the
  folder except the legacy comparison files, which use `jquery_*`.
- `shell/git-cli/` — README-AI file is `git_readme_readmeai.md`.
- `py/scikit-learn/` — README-AI file is `scikit_readme_readmeai.md`.
- `shell/notes-cli/` — README-AI file is `notes_readme_readmeai.md`.
- `shell/command-laucher/` — folder name typo for command-launcher; README-AI
  file is `command-launcher.md`.
